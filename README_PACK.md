# SEBELUMJADIAPI — CODEX BLUEPRINT PACK

Paket ini **belum berisi source code website**. Ini adalah spesifikasi dan referensi agar Codex bisa membangun proyek dengan fase yang jelas.

## Cara pakai di Windows

1. Buka PowerShell di `Documents`.
2. Jalankan `npm create vite@latest sebelumjadiapi -- --template react-ts`.
3. Masuk `cd sebelumjadiapi` dan jalankan `npm install`.
4. **Salin seluruh isi folder paket ZIP ini** ke dalam folder `sebelumjadiapi` hasil Vite. Pada hasil akhir, pastikan `AGENTS.md` ada di root dan `SEBELUMJADIAPI_MASTER.md` ada di `docs/`.
5. Buka folder itu di VS Code/Codex.
6. Ikuti `CODEX_START_HERE.md` — mulai PHASE 0 dulu.

## Isi

- `docs/SEBELUMJADIAPI_MASTER.md` — blueprint lengkap.
- `AGENTS.md` — pedoman perubahan untuk Codex.
- `CODEX_START_HERE.md` — langkah Windows dan prompt awal.
- `docs/PROJECT_STATUS.md` — catatan milestone yang diperbarui setiap fase.
- `docs/DECISION_LOG.md` — rekam keputusan dan batas scope.
- `references/academic/` — dua PDF asli user sebagai sumber utama.
- `references/screenshots/` — screenshot referensi UI WWF dan Of the Oak.
