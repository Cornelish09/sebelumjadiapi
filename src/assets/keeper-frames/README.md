# Bingkai Kartu Penjaga Gambut

Simpan bingkai sebagai PNG transparan dengan nama di bawah. Bagian tengah sebaiknya transparan agar nama, progres, dan gambar tetap terbaca. Bingkai ditampilkan di atas desain kartu.

| Template | Kartu 1200 × 630 px | Story 1080 × 1920 px |
| --- | --- | --- |
| Kanopi | `kanopi.png` | `kanopi-story.png` |
| Arus | `arus.png` | `arus-story.png` |
| Serat | `serat.png` | `serat-story.png` |
| Fajar | `fajar.png` | `fajar-story.png` |
| Rintik | `rintik.png` | `rintik-story.png` |

Setiap PNG dipakai otomatis saat template dan formatnya dipilih. Lakukan build ulang setelah menambahkan atau mengganti berkas.
